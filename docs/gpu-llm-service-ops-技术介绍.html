它做什么、不做什么

在 SSH 可达的 GPU 机器上，把 conda 环境和服务维持在可工作状态。四端软链到同一份仓库：skills/gpu-llm-service-ops。

做

起停 vLLM / ComfyUI / ai-toolkit / OneTrainer / kohya / LlamaFactory。重装后恢复 /nfs。下模型并软链。Mac 隧道。用量统计。JuiceFS / NFS / 本地选型。KAS 多机 + NCCL/IB。

不做

不写创意 prompt，不验收片子。不往共享 NFS env 里随手 pip。不宽泛 pkill。不把别人的任务当自己的。

只读探针

改任何东西之前，一次 SSH 里尽量跑完：hostname、whoami、conda info --envs、nvidia-smi、df -h / /home/share /nfs、mount | grep /nfs、ls -l /opt/conda/envs、tmux ls、相关端口的 ss -ltnp。

优先非交互 SSH 和 tmux send-keys / capture-pane。复杂命令写成远端 /tmp 脚本再 send 路径，避免引号被吃掉。

共享 NFS 环境

Juscent 栈的真源是 /nfs/envs/<name>。/opt/conda/envs/<name> 只是软链。激活要显式：

source /opt/conda/etc/profile.d/conda.sh
conda activate /nfs/envs/comfyui    # 优先绝对前缀
# conda activate comfyui            # 依赖 /opt/conda/envs 软链还在

改过的 PATH 不等于激活成功。bin 脚本用 set -u，conda activate 前后要暂时 set +u（deactivate hook 会碰到未设置的 CONDA_BACKUP_*）。

不要往 /nfs/envs 里 pip / 解压 / 编译。 NFS 写入约 145 MB/s，JuiceFS 约 950 MB/s，且跨主机共享。装到本地盘再挪，或接受串行慢写。

重装恢复顺序：挂回 /nfs → 重建 /opt/conda/envs/* 软链 → 核对代码路径 → bin start / status。细节在 references/nfs_envs_and_juscent_bin.md。

GPU 绑定怎么验

双实例（每卡一个）时，不要看 nvidia-smi 显存。空闲服务两张卡都是约 0 MiB。看 /proc/<pid>/environ 里的 CUDA_VISIBLE_DEVICES。

ultra 绑定脚本是本机的，不在 share bin：comfyui-gpu0.sh、ai-toolkit-gpu1.sh、onetrain-gpu1.sh。ai-toolkit 的 output / datasets 与 train-1 共用 share，同一 job 目录只能一个写者。

模型库与软链

LLM 类进 /home/share/game/seasun/models。ComfyUI / 图像生成进 /home/share/game/juscent/models。ai-toolkit 按命名空间选：Flux / Qwen-Image / ComfyUI 兼容训练走 Juscent；泛 LLM 训练走 Seasun。

ComfyUI 本地模型目录软链到共享库，不要把多 GB 文件拷进源码树。改过软链后跑 scripts/audit_model_links.sh。缺模型、自动下载、断链：references/comfyui_node_model_ops.md。

存储选型

三套挂载：JuiceFS（/home/share1、/home/share）、NFS（/nfs）、本机 overlay。基准必须冷读和热读分列，不要平均。方法与数字在 references/storage_io_bench.md。多机训练：references/kas_multinode_ib.md（KAS_* → torchrun、NCCL 走 IB 的核对方法）。

任务统计

问「最近 N 天跑了多少」时保持只读。默认一台 train-1 就能覆盖两套栈。

ai-toolkit · 可信

aitk_db.db 的 Job 表能活过重启。created_at 是毫秒 epoch。报总数 + 按日 + 按状态。stopped 且 step=0 是建了又撤，不是真训练。

ComfyUI · 不可当任务数

/history 在进程里，重启即空。耐久代理是 output/ 的 mtime 文件数，那是产物不是任务，而且目录是共享的。必须两句都写出来。

脚本实现细节

scripts/gpu_task_counts.sh

Bash，set -euo pipefail。必填 --since "YYYY-MM-DD HH:MM:SS"（主机本地时）。--ssh 同时打两套栈；可拆 --train-ssh / --comfy-ssh，或 --skip-comfy / --skip-train。

远端用 printf '%s\n' "$payload" | $SSH 'bash -s' 灌脚本，避免本机展开搞乱引号。ai-toolkit 侧找 sqlite3（先 /opt/conda/bin/sqlite3），库默认 aitk_db.db。SQL 把毫秒除 1000 再 datetime(...,'unixepoch','localtime')，按 SINCE 过滤。ComfyUI 侧 curl 本机 8188/history，并按 mtime 扫共享 output/；history 最早一条若晚于窗口起点，打印 WARNING。

scripts/vllm_stream_ttft_client.py

打 OpenAI 兼容流式接口。分别记 /health RTT、响应头延迟、端到端 TTFT，再估服务侧时间。用来把隧道/网络基线和模型首字延迟拆开。结果可落 JSON/CSV。

scripts/audit_model_links.sh

核对 ComfyUI 本地目录到共享库的软链：悬空、指错 store、重复实体。改模型布局后当验收，不是装饰。

vLLM 启动约定

tmux send-keys -t vllm \
  "bash /home/share/game/seasun/vllm/start_vllm.sh 2>&1 | tee /tmp/vllm.log" Enter

不要手写 vllm serve 参数。换模型只改脚本里的 model_path / model_name。

红线

  • 先探针再改；用户要方案就先写 .md 等确认。
  • 不往 /nfs/envs 随手装包。
  • 不宽泛 pkill；不碰别人的 tmux / 目录 / 服务。
  • 绑卡看 environ，不看空闲显存。
  • ComfyUI history ≠ 任务数；output 文件 ≠ 任务数。
  • 存储基准冷热分开报。JuiceFS 的 bin/ 可能是 root 的，新建常要 sudo。

更细的命令模板：references/gpu_service_runbook.md、comfyui_server_runbook.md、onetrainer_runbook.md。
