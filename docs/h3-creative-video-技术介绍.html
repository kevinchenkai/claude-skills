它做什么、不做什么

在远端 ComfyUI 上做 MiniMax-H3 视听短片：写/改 prompt、接线、探针、出片、用脚本量、用人眼人耳签收。环境起停交给 gpu-llm-service-ops。

做

T2VA / I2VA / FL2VA / L2VA / Ref2VA。官方字段顺序。成对 seed 实验。全黑/NaN/切镜/冻结诊断。filmstrip。三种交付状态。

不做

T2VA 不造关键帧、不插空白图。不把 FL2VA 的帧数上限套到 T2VA。不把「运动比升高」当成片子变好——可能是模型自造的特写。

五种 conditioning mode

先看素材角色，再看「只出方案还是端到端」。一张图没说清是端点还是身份参考，必须先问，不能擅自当 I2VA。

模式锚定输入接线
T2VA只有文字不接 first/last frame；图里不能有 image loader 喂这两口
I2VA一张明确首帧 + 文只接 first_frame
FL2VA首+尾 + 文两口都接；先看两张图能不能走出连续路径
L2VA一张明确尾帧 + 文只接 last_frame；本地 profile 未充分标定，先探针
Ref2VA身份/风格/动作/声音参考专用权重 + MiniMaxH3ReferenceToVideo；冻结标签顺序

参考视频、参考音频或混合一般参考 → Ref2VA。prompt 里写「墙上有张照片」只是场景，不算输入图。

三字段与六段式

Base 四模式字段顺序固定，中间空行：

integrated_multimodal_description: ...
overall_soundscape: ...
non_diegetic_music: ...

T2VA 直接从第一字段起，前面不能有 Picture 对齐行。I2VA / FL2VA / L2VA 各有官方首行，lint 按整行匹配。

Ref2VA 换成六段，不能套三字段开头：subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music。标签 <Subject N> / <Picture N> / <Video N> / <Audio N> 先冻结再写。

对白、歌词、画面内文字必须逐字保留。详细 brief 不当成可以丢掉的草稿。已是官方结构且用户没要优化，只校验不改写，并保留 source / final 哈希。

运行上限不能跨模式借

官方 prompt 指南不定义本机图的推理天花板。每次记下：模式、主机、checkpoint、图/runner 哈希、节点、启动参数、fps、尺寸、帧数、步数、采样、调度、绑卡。

模式已记录的证据不要推论
T2VA107 帧接线探针；192 / 243 帧 24fps 出片成功尚未建立 T2VA 上限
I2VA107 帧探针；192 帧官方复现不要假定 FL2VA 的尾巴行为
FL2VAn % 17 == 5 且 n ≤ 277；再高出现过全黑静音不要把这条天花板借给 T2VA / Ref2VA
L2VA / Ref2VA官方结构已知，本地生产 profile 未标定先低步探针并验像素

通用记录：边长能被 16 整除，面积 ≤ 1032192，24fps。换模型/图/节点后重测。没试过的模式×画幅×帧数，先低步跑并看像素；能 decode 或 success 不够。

创意生产 vs 因果实验

这是工作模式，不是 conditioning mode。混在一起会把「看起来顺」写成机制解释。

创意生产因果实验
目的选出最好的一条测一根杠杆
能说按事先记分卡偏好某候选成对 seed 都同向，且超过 seed 噪声地板
不能说单因子因果单 seed 上的机制故事

验收分层

  1. 像素/流：帧数、尺寸、空白、NaN、音频策略、A/V 时长差。
  2. 事先声明的数字门：尾段活动比、绝对活动、末帧冻结时长、切点（仅当 brief 要求）。
  3. 人眼：T2VA 特别看人物/物体一致性（没有图锚）。Ref2VA 按每个 reference role 分项看。
  4. 人耳：对白是否原句、音轨是复制还是参考。

交付只许三种：Accepted delivery / Creative prototype / Invalid output。数字门过线不能证明东西变好——运动比升高可能是模型自造特写。仓库总则：判据只能证伪，不能证明好。

尾巴冻结实验写在 known_findings.md，带模式范围。FL2VA 里证伪过的措辞，不能自动当成 T2VA / Ref2VA 也无效。

失败按模式选杠杆

主体不见：T2VA 先改具体事实和时间线，再换 seed；图模式先查端点图；Ref2VA 先查接线/标签/retention 行。

身份漂：T2VA 简化并在切镜处重复稳定外形；图模式查端点一致性；Ref2VA 去掉冲突参考，比较 match 与 max。

声音错：base 模式改音频字段和对白原文；Ref2VA 重数 <Audio N>（启用的参考视频音轨先编号，独立音频往后排）。

脚本实现细节

依赖在能跑 ffprobe / 解码的环境执行。JSON 进证据清单。

scripts/h3_prompt_lint.py

校验模式、字段顺序、镜头号、时间戳、对白标签。常量：

BASE_FIELDS = (integrated_multimodal_description, overall_soundscape, non_diegetic_music)
REF_FIELDS  = (subject_definitions, summary, retention_analysis,
               detailed_description, overall_soundscape, non_diegetic_music)

detect_mode() 看第一行非空：subject_definitions: → ref2va；integrated_multimodal_description: → t2va；整行等于 I2VA 官方句 → i2va；FL2VA_RE / L2VA_RE 抽镜头号和秒数。可 --mode 强制。Ref2VA 要传冻结的 --pictures --videos --audios，与标签计数对齐。

python scripts/h3_prompt_lint.py prompt.txt --mode ref2va --duration 5 \
  --pictures 1 --videos 1 --audios 1 --json

scripts/h3_verify.py

门：期望帧数/宽高、空白帧、视频 NaN、音频策略（required / optional / forbidden）、静音 RMS 地板、A/V drift。例：

python scripts/h3_verify.py output.mp4 \
  --expected-frames 277 --expected-width 736 --expected-height 1312 \
  --audio required --min-audio-rms 0.000001 --max-av-drift 0.25 --json

scripts/h3_freeze.py

量整帧尾巴活动和末段冻结。只能证明整帧动或不动，不能证明主体在动（背景动、人冻住会过线）。只在 brief 要求结尾持续动时才当交付门。

scripts/h3_cutdetect.py

找孤立硬切，和期望时间比。看不见叠化。公差事先写进工单。

scripts/filmstrip.py

时间接触表，给人眼扫故事，不替代全分辨率抽帧。

红线

  • 先路由模式，再套任何规则。实验结论带模式范围。
  • 提交前 lint。T2VA 证明图上没有端点图输入。
  • 判据写在成片之前；用已知好/坏样本标定。
  • 单 seed 不做机制解释。成对 seed 不一致就停嘴。
  • 负面结果完整记录，不事后挪线。
  • 独立生成的音频不要承诺能无缝拼接。
