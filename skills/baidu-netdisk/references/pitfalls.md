# 踩过的坑（10-10～10-25，movieDB 片源入库与本 skill 实测）

## 凭证与权限

- **AI 不碰登录凭证。** BDUSS / STOKEN / 密码属于"把凭证填进字段"，用户在对话里给了也不能代填、代跑 `login`。做法：`login_hint.sh` 打印 `read -rsp` 版命令，用户在终端里自己输入，回复"已登录"后 `who` 复核。
- **转存需要 STOKEN。** 只用 BDUSS 登录时 `ls`、下载、上传都正常，`transfer` 失败。
- **永久删除用户自己做。** `rm` 进回收站，回收站清空/过期后不可恢复；`recycle` 的删除、清空直接不可恢复。`bpcs.sh` 拒绝这两类命令并打印原命令给用户。
- **登录态文件含凭证。** `~/.config/BaiduPCS-Go/pcs_config.json` 默认 660，建议 600；不要 cat、不要拷到共享盘或仓库。`config` 只用 `bpcs.sh config` 看（已过滤凭证行）。

## md5 与完整性

- **网盘 md5 经常不是文件真实 md5。** `meta` 自己就标「md5 (可能不正确)」。实测：《鱿鱼游戏》S02 7 个文件、`/01.LLM` 下一个 m4a，网盘 md5 与本地 md5 完全不同；《王国》S01 6 个文件一致。已知的两种还原变换（按位 xor (i&15) + 8 字符块互换，两种顺序）都对不上，**不要再试着还原**。
- **BaiduPCS-Go 不替你校验。** 每个文件都会打「跳过文件有效性检验」。`verify.py` 的判定：大小必须全对；md5 全对 = OK；多文件目录 **全不对**但大小全对 = 网盘 md5 不可用（以本地 md5 为准写 MD5SUMS）；**部分对部分不对** = FAIL（更像真损坏，重下不一致的那几个）。
- **单个文件分不清。** 目录里只有一个文件时，"md5 不一致"既可能是网盘 md5 不可用，也可能是坏了。`verify.py` 返回 `INCONCLUSIVE_SINGLE_MD5`（退出码 2）；重新下载到另一目录并用 `--peer` 比较，两份文件一致后返回 `OK_REDOWNLOAD_MATCH`。
- **文件名以网盘为准。** 下载日志里的「文件路径」是网盘全路径；`verify.py` 按 `--remote` 前缀截成相对路径匹配。下载后改过名的目录，日志匹配不上，用 `--meta` 现查（网盘也改过名才能查到）。

## 目录与版本

- **目录名以网盘实际为准**：用户说「庆余年 S01」，网盘是 `庆余年S01`。先 `ls`。
- **同一文件夹两套版本**：《庆余年》S02 顶层是 1080p，子目录里另有 4K。先列给用户选，别全量下（4K 那套 68 GB）。
- **`d --saveto DIR /网盘/目录` 会建 `DIR/目录/`**；单个文件直接放在 `DIR/` 下。

## 监控误报（status 脚本写错过三次）

1. **mawk 打印大于约 1e10 的数会变成科学计数法**（`1.06858e+10`），bash 算术直接炸成 0 → "下载量 0"。字节数用 Python 累加，或 awk 里 `printf "%.0f"`。
2. **追加写的日志里有上一次运行的 `ALL_DONE`**，新一轮刚启动就被判"已完成"。`download.sh` 每次写 `RUN_START <run>`，`status.py` 只看最后一个 `RUN_START` 之后的行。
3. **改名后统计脚本还按旧目录名找**，进度"倒退"。改名阶段的统计要同时认新旧名字，或在改名前先做完最终统计。
- 重新挂上监控时第一条速度是 0 基线，不是卡住。

## 运行环境

- **长任务进远端 tmux。** 经跳板机（hanhai）的长 ssh 命令会被断开（"Connection closed by remote host"），下载会跟着断。
- **安全封装必须识别全局参数。** BaiduPCS-Go 的语法是 `[global options] command`；只检查 `$1` 会被 `--verbose rm` 绕过。当前 `bpcs.sh` 拒绝除帮助、版本之外的全局参数，并使用命令允许列表。
- **`pkill -f` 会匹配到你自己的 ssh 命令行**，把自己杀掉；按 PID 杀，或用 `[B]aiduPCS` 这种括号技巧。
- **非 SVIP 并发上限 1**（`max_parallel` 的说明里写着）。实测 SVIP 约 28 MB/s。
- **下载到 JuiceFS 共享盘**：大文件顺序写没问题；之后算 md5 约 300 MB/s，几百 GB 要几十分钟，`verify.py --workers` 默认 6。
- **tb 上 github.com 不通**（codeload 可以），装二进制从已装好的机器拷。
